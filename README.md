**데이터분석 경진대회 참가 기록 - 팔당댐 홍수 안전운영에 따른 한강 수위예측 AI 경진대회**


<h1>대회 개요</h1>

- 대회명: 팔당댐 홍수 안전운영에 따른 한강 수위예측 AI 경진대회
- 목표: 팔당댐 수위/유량 및 각처 강수량 등 가용한 관측값들을 토대로 주요 4개 교량(청담대교, 잠수교, 한강대교, 행주대교) 수위를 예측
- 대회 기간: 2022.07.25 - 2022.09.02
- 관련 링크: https://dacon.io/competitions/official/235949/overview/description

<h1>저장소 구성</h1>

실행 환경
- 프로세서: Intel(R) Core(TM) i7-10700K CPU @ 3.80GHz 3.80 GHz 
- RAM: 64.0GB
- 시스템 종류: 64비트 운영 체제, x64 기반 프로세서 
- 에디션: Windows 10 Home 버전 21H2 OS 빌드 19044.1889
- 파이썬 버전: 3.8.6
- 기타 라이브러리 버전은 `requirements.txt`에 기록

주요 파일
- `report.pptx`: 예측 과정 설명 파일
- `main.py`: 예측 데이터 생성 코드

기타 (ideas/)
- `lgbm.py`: LGBM 모델을 사용하여 예측을 생성하는 코드
- `lgbm_hyptune.py`: LGBM 모델의 최적 하이퍼패러매터를 탐색하는 코드
- 등등...

<h1>주된 난점 및 대책</h1>

- 대회에서 제공하는 관측치 종류가 제한적
    - 한강홍수통제소의 OpenAPI를 통해 여러 댐의 방류량이나 여러 지점의 강수량 데이터를 내려받음
- 수많은 결측치
    - 지나치게 결측치가 많은 변수들은 제외하면서도, 결측치에 대응가능한 예측 모형 사용
- 이외 분석 과정에 대한 설명은 `report.pptx`에 설명되어 있음
